# Portfolio Governance Baseline

This is a health/diagnostic research asset and must not be represented as clinically validated merely because a model produces predictions.

- Document dataset provenance, population, labels, limitations and evaluation methodology.
- Separate research metrics from clinical performance.
- Test false positives, false negatives, calibration and distribution shift where applicable.
- Do not expose patient-identifying information unnecessarily.
- Do not make clinical decisions autonomously without appropriate professional oversight and validation.
- Clearly label prototype/research status and avoid unsupported efficacy claims.
